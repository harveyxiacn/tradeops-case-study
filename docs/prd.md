# TradeOps 应用需求文档

文档状态：待开发设计。版本 0.1。独立模拟作品；无真实客户、订单、支付与物流连接。目标是展示需求分析、流程控制、SQL 和验收，而非开发全功能 ERP。

## 用户与任务

Sales 创建询盘和报价、补缺失字段、提交审批、查看自己负责的记录。Manager 审核权限范围内且非本人创建的报价、给出理由、查看逾期。Operations 查看已批准版本、更新模拟跟进记录。Admin 管理演示账号与基础配置，不自动获得批准业务权限。Reviewer 为只读作品演示角色。

MVP 为单组织应用，数据库保留 organization_id 并在服务端检查边界；不提供多组织注册、收费和完整 SaaS 管理。使用合成身份；仅本地 demo 可使用预置账号，任何公开部署必须先落实认证、关闭重置接口并更换密钥。

## 范围

必须有询盘列表、询盘详情、报价编辑、审批详情、审计记录与简单运营报表。允许保存草稿；提交时验证完整性；所有报价均需独立审批。已批准报价只能导出带编号、版本和“Demo—not a commercial offer”标识的文件。

不做真实邮件、采购、库存扣减、发票、税务、信用审核、实时外汇、自动 AI 批准。付款期是模拟业务字段，不代表法律或财务意见。将未来订单管理留在 backlog，不混入 MVP 截图。

## 页面与交互

| 页面 | 内容 | 主要动作 | 空／错误状态 |
|---|---|---|---|
| Inquiry list | 编号、客户代号、负责人、状态、更新时间 | 按状态／负责人筛选，建草稿 | 无记录给清空筛选入口；加载失败可重试 |
| Inquiry detail | 原文、结构化字段、缺失项、关联报价 | 编辑自己的草稿，生成报价 | 指出具体缺失字段，不丢已填内容 |
| Quote editor | 产品行、数量、单价、成本、币种、折扣、付款期 | 保存、预览计算、提交 | 服务端错误对应字段；不以浏览器计算为准 |
| Approval detail | 不可变报价快照、计算结果、风险提示、历史 | 批准、驳回并填写理由 | 版本过期提示刷新；自批返回权限错误 |
| Operations | Pending 数、逾期数、各币种净额、缺失字段 | 查看明细与导出 | 不把不同币种直接相加；无数据不除零 |

简易 wireframe：上方为编号／状态／版本；左侧为询盘与客户资料；中间为报价明细；右侧为风险与审批动作；底部为按时间排序的审计事件。屏幕窄时纵向排列，状态同时用文字表示，不只靠颜色。

## 功能要求

FR01 草稿包含客户代号、询盘正文、负责人；可暂缺产品、数量和目的地。

FR02 提交必须有 SKU、正整数数量、非负单价与成本、HKD／USD、目的地、付款期和有效期；净额必须大于 0，折扣 0–50%，日期不得早于提交日期。超出范围返回明确错误，不能默默修正。

FR03 同一版本只允许一个终结决定。并发审批使用数据库约束和条件更新，第二个请求返回已决定或 409，不能覆盖首个决定。

FR04 Sales 只能编辑 Draft；Pending 需撤回后创建新 Draft 版本，旧版本保留为 Withdrawn；Rejected 可复制为新版本；Approved 如需修改，先由有权限人员 supersede 并创建新版，新版再次审批。

FR05 驳回、撤回、作废及审批必须有 actor、时间、版本、动作、理由。普通用户不能修改／删除审计历史。应用级追加写入不等于防数据库管理员篡改。

FR06 CSV 导出包含 quote_id、version、currency、net_amount、fx_to_hkd、net_hkd、status；以文本安全方式处理以 =、+、-、@ 开头的自由文本，避免电子表格将其当公式。

FR07 基础报表仅汇总当前有效版本；明确 Draft／Pending／Approved／Rejected／Withdrawn／Superseded 的分母和排除项。当前有效版本指 quote.current_version 指向版本，不等于最新 updated_at。

## 非功能验收目标

在 README 记录硬件和数据规模，以 500 条询盘、20 个并发本地测试用户为演示目标；普通列表 API p95 目标小于 1 秒。这是待测目标，不是现有性能。筛选与分页必须在服务端处理。所有越权、自批、重复决定、版本冲突用例必须通过；任何高风险失败阻止公开 demo。

## Definition of Done

从干净数据库迁移并导入合成数据成功；一条正常和四条异常流程可演示；核心 UAT 有实际结果和证据；安全边界用真实 API 请求验证；README 写清模拟属性与未实现项；发布 commit 与测试报告一致。截图、设计稿和代码生成成功均不足以单独构成完成。
